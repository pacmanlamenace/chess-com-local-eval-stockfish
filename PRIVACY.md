# Privacy Policy

Chess.com Local Eval (StockFish) does not collect, transmit, sell, or share personal data,
game data, browsing history, telemetry, or analytics.

The extension reads the move list from the Chess.com game page currently open
in Firefox. Stockfish analyzes those moves locally on the user's device. No
game moves or analysis results leave the browser.

The extension does not create an account, use cookies, contact a remote API,
or store user data. Its only network access is the Chess.com page that the user
has already chosen to visit; all executable code and the Stockfish WebAssembly
engine are packaged with the extension.

Last updated: August 31, 2026.
