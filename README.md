# Chess.com Local Eval (StockFish)

Private repository for the Firefox extension that provides local Stockfish post-game analysis for completed Chess.com games.

## Install

[Install Chess.com Local Eval from Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/chess-com-local-eval/)

The extension deliberately disables analysis during live or in-progress games. All analysis runs locally in Firefox; no game data, telemetry, or analytics is transmitted.
